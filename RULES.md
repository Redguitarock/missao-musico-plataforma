# RULES — MISSÃO MÚSICO

## PRINCÍPIOS

* Simplicidade acima de tudo
* Evitar overengineering
* Código modular
* Escalável desde a base

---

## FRONTEND

* Mobile-first obrigatório
* Uma ação principal por tela
* Evitar poluição visual

---

## BACKEND

* Usar Supabase como base
* Evitar lógica complexa desnecessária
* Centralizar regras no backend

---

## DADOS

* Normalização básica
* Relacionamentos claros
* Evitar duplicação

---

## PRODUTO

* Sempre priorizar:

  * jornada guiada
  * progresso do usuário
  * diagnóstico

---

## PROIBIDO

* Criar features fora do escopo
* Criar sistemas complexos antes do tempo
* Reescrever partes já feitas sem necessidade
